# ✈️ Jadoo — Travel Agency Landing Page

Landing page responsiva desenvolvida para uma agência de viagens, construída com **HTML5** e **CSS3** puro a partir de um layout moderno de UI/UX pelo figma.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estruturação semântica da página
- **CSS3** — Estilização com Flexbox, Grid, posicionamento, sombras, gradientes e micro-interações
- **Google Fonts** — Tipografia (*Poppins* e *Volkhov*)

---

## ✨ Destaques do Projeto

- Layout fiel ao design original, com elementos decorativos e camadas sobrepostas[cite: 2].
- Animações suaves de `:hover` nos cards, botões, links e ícones[cite: 2].
- Design responsivo adaptado para diferentes tamanhos de tela.
- Código limpo e organizado com separação entre estrutura e estilo.
